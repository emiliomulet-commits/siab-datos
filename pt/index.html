O que é

Um espaço de dados são regras, não um armazém

Não há uma grande base de dados central. Há organizações que se reconhecem entre si, um catálogo do que cada uma oferece e contratos que dizem exatamente o que se pode fazer com cada dado.

Soberania

O dado fica em casa de quem o guarda. É quem decide quem acede, para quê e durante quanto tempo.

Contratos ODRL

As condições de utilização são escritas para que uma máquina as aplique. Sem contrato, não há acesso.

Confiança Gaia-X

Cada organização identifica-se com credenciais verificáveis emitidas por serviços de confiança.

IA sem mover dados

Os modelos são treinados onde está o dado (aprendizagem federada e computação confidencial).

Primeiro vertical

Espaço de dados para clínicas dentárias com IA sobre Microsoft Azure

Uma rede de clínicas que treina e melhora a IA de diagnóstico sem que os dados dos doentes saiam de cada clínica. Microsoft dentro do nó; normas abertas na fronteira.

O que inclui

  • Nó de dados por clínica no Azure: processo clínico em FHIR e imagem em DICOM, pseudonimizados na origem.
  • IA de apoio ao diagnóstico: cáries interproximais e perda óssea periodontal em radiografia, com validação do médico dentista.
  • Assistente do processo: resumo do historial e rascunho revisível do plano de tratamento.
  • Conector Eclipse EDC, catálogo HealthDCAT-AP e contratos ODRL entre membros.
  • Treino federado entre clínicas com computação confidencial.
