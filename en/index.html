What it is

A data space is a set of rules, not a warehouse

There is no big central database. There are organisations that recognise one another, a catalogue of what each one offers and contracts that state exactly what can be done with each piece of data.

Sovereignty

Data stays with whoever holds it. They decide who accesses it, for what and for how long.

ODRL contracts

Terms of use are written so that a machine can enforce them. No contract, no access.

Gaia-X trust

Each organisation identifies itself with verifiable credentials issued by trust services.

AI without moving data

Models are trained where the data is (federated learning and confidential computing).

First vertical

A data space for dental clinics with AI on Microsoft Azure

A network of clinics that trains and improves diagnostic AI without patient data ever leaving each clinic. Microsoft inside the node; open standards at the border.

What it includes

  • A data node per clinic on Azure: medical records in FHIR and imaging in DICOM, pseudonymised at source.
  • Diagnostic support AI: interproximal caries and periodontal bone loss on X-rays, validated by the dentist.
  • Patient file assistant: summary of the history and a reviewable draft treatment plan.
  • Eclipse EDC connector, HealthDCAT-AP catalogue and ODRL contracts between members.
  • Federated training across clinics with confidential computing.
